# Sonus 安卓版 0.6.0（测试版）

这一版接上服务器的播放库（`sonusRenditions`）：手机和平板上可以按网络分别选择音质（Wi-Fi 默认无损，移动网络默认 Opus 160，也可两项均选无损以强制无损），新增基于 EBU R128 响度测量的音量均衡，并在播放器与平板播放栏上显示当前正在播放的音质档位。

## 下载

装着 0.4.x 或 0.5.x 的话，在 设置 › 更新 里就能更新到这一版。也可以下载附件里的 APK 直接覆盖安装：装上后叫「Sonus 测试版」（包名 `com.creeperux.sonus.debug`，版本 0.6.0 / `versionCode = 10`），需要 Android 13 及以上，登录不丢。

## 音质与音量

- **Wi-Fi 下的音质**（设置 › 音质与音量）：自动 / 普通 / 高 / 极高 / 无损，默认「自动」（= 无损，保留原采样率与位深）。
- **移动网络下的音质**（设置 › 音质与音量）：自动 / 普通 / 高 / 极高 / 无损，默认「自动」（= 高，Opus 160）。两项都选「无损」即为强制无损。
  - 按系统报告的网络类型（Wi-Fi / 计费移动网络）自动切换，换网络后从下一首起生效，不中断当前播放。
  - 网速跟不上导致持续缓冲时，仅在选了「自动」的情况下临时降一档，手动选定的档位不会自动降档。
  - 有损三档对应服务器播放库的极高 Opus 256、高 Opus 160、普通 Opus 96；在开启播放库的服务器上，DSF、APE 等格式也能以无损 FLAC 播放。
- **音量均衡**（设置 › 音质与音量）：默认「关」，可选安静（−18 LUFS）/ 正常（−14 LUFS）/ 大声（−11 LUFS），开启时默认「按专辑」（可切「按歌曲」）。
  - 优先使用服务器播放库测得的 EBU R128 响度与峰值数据（低于目标响度时用 `LoudnessEnhancer` 提升并按真峰值防削波；高于目标响度时平滑衰减）；连接未开启播放库的服务器时回退到曲目回放增益标签。
- **始终用原文件**（设置 › 高级）：默认关闭；开启后始终直接请求服务器原始文件，音质设置不生效，便于排查问题或对比听感。
- **播放栏与全屏播放器音质徽标**：显示当前歌曲实际播放的格式与规格（例如 `无损 · 96 kHz/24 位`、`无损 · 44.1 kHz/16 位`、`Opus 160`），实时读取服务器返回的 `X-Sonus-*` 响应头。

## 测试情况

- 电脑端单元测试：
  - `:core:test`：**84 项通过**（0 失败，1 项仅真机/特定环境跳过），含新增 4 项 `QualityPolicyTest`（档位解析、仅自动降档、EBU R128 与真峰值保护、回放增益回退、徽标格式、`getSonusRenditions` 协议解析）。
  - `:app:testDebugUnitTest`：**23 项通过**（0 失败），含新增 `Settings` 音质/响度/原文件默认值与持久化测试。
  - `:app:assembleDebug` 与 `:app:assemblePreview`（含 R8 压缩混淆）均构建通过。
- 模拟器完整设备测试（后台无窗口静音运行，对接演示服务器）：
  - `sonus-phone`（Android API 37）：**12/12 执行项通过**（0 失败，1 项仅两步验证服务器适用跳过），含新增 `qualitySettingsLoudnessAndBadgeWork`（设置页切换、状态断言与全屏播放器徽标截图）。
  - `sonus-tablet`（Android API 37）：**12/12 执行项通过**（0 失败，1 项仅两步验证服务器适用跳过），含平板设置页与底部播放栏音质徽标截图。
- 看过的截图：手机与平板的「音质与音量」「高级」设置页、手机全屏播放器与平板底部播放栏的音质徽标。
- **还没有验证的**：
  - 真手机上的真实蜂窝网络切换与物理蓝牙/有线耳机 `LoudnessEnhancer` 听感尚未实测。
