# Sonus 安卓版 0.3.1（测试版）

播放器下滑收起更干脆，上拉打开时封面和面板同步。

## 下载

附件里的 APK 是测试版：装上后叫「Sonus 测试版」（包名 `com.creeperux.sonus.debug`，版本 0.3.1），需要 Android 13 及以上，可以直接覆盖安装 0.3.0，登录不丢。

## 修正

- **下滑收起时，播放器整块跟着手指走。** 以前封面会单独飞回迷你播放条，和播放器下滑叠成两段动作；现在收起时封面就是播放器的一部分，一起下去，迷你播放条直接出现在下面。
- **上拉打开时，播放器从迷你播放条展开。** 以前面板从屏幕最底部升上来，封面却从迷你播放条的位置出发，前一段封面会飘在面板上方，看起来不同步；现在面板的上沿从迷你播放条的位置开始、跟着手指往上走，封面全程在面板里从小长到大。面板刚出现的一小段淡入，不会一下子盖住底部标签。
- **松手后按手指的速度收完。** 以前松手后不管甩得多快，剩下的路程都固定走 320 ms 的减速曲线，末尾拖得慢；现在按剩下的距离和手指速度决定，最多 200 ms，并且是加速离开。点收起按钮或按返回键也是 200 ms 加速收起。
- **轻甩能被认出来。** 以前拖动收起时，手指的位移和速度是按正在跟着手指移动的播放器自己的坐标算的，算出来偏小：播放器会落后于手指，轻甩几乎认不出来。现在按屏幕坐标算。

## 测试情况

- 电脑上的测试：核心库和 App 单元测试 75 项全部通过；调试构建和优化测试版都能编出来。
- 在这台电脑带窗口的模拟器上，用触屏试过上拉打开和下滑收起，也截了拖动途中的画面：打开时封面一直在面板里随面板长大，收起时整块下去。
- 设备测试（演示服务器、Rust 服务器）还没跑；真手机上还没试。

## 已知限制

- 测试版用调试密钥签名；正式版的签名密钥还没有建。
- 手感要在真手机上判断：模拟器没有振动，鼠标或触屏拖动和手指在手机上的感觉不完全一样。
