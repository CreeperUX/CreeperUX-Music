# Sonus 0.7.0

这一版打磨了界面和动效：右侧面板、设备面板、换歌、换页、音乐库的展开和收起都有了看得出来的动画；顶栏和左侧音乐库会标出你正在看哪一页；专辑页的音质改成了徽章；另外修了十来处对齐和配色的小问题。

## 下载

| 文件 | 说明 |
|---|---|
| `Sonus-0.7.0-x64-setup.exe` | 安装程序，普通 Intel / AMD 电脑（推荐） |
| `Sonus-0.7.0-ARM64-setup.exe` | 安装程序，骁龙等 ARM 电脑（推荐） |
| `Sonus-0.7.0-x64.msi`、`Sonus-0.7.0-ARM64.msi` | 和安装程序里装的是同一个 MSI |
| `CreeperUX-Music-0.7.0-x64-setup.exe`、`CreeperUX-Music-0.7.0-ARM64-setup.exe` | 和上面的安装程序完全相同，只是用了旧名字：0.3.0 按这个名字找更新 |

只为当前用户安装，不需要管理员权限，装在 `%LOCALAPPDATA%\Programs\Sonus`。安装程序没有数字签名，第一次运行时 SmartScreen 可能会提示，选「更多信息 › 仍要运行」。

## 动效

所有动画都由 Windows 的合成器来画，不占界面线程，也不一帧一帧地改布局。在 Windows 设置里关掉「动画效果」后，一切直接显示结果。

- **右侧面板**：打开和关闭时从右边滑进、滑出。
- **设备面板**：点播放栏的设备按钮，设备列表从面板底部升起，盖住原来的内容；关闭时沉回去。开到一半又关、关到一半又开，都从当时的位置接着走。
- **换歌**：播放栏左下角的封面轻轻放大出现，歌名和艺人从旁边滑进来。
- **「正在「…」上播放」横条**：别的设备开始出声时，横条从下面升起，设备按钮跟着弹一下；那台停下时，横条沉回去。中途变了也能接着走。
- **换页**：新页面向上浮起、淡入。在搜索框里边打字边出结果时只淡入，不再每打一个字整页跳一下。
- **音乐库展开和收起**（列表 ↔ 只有封面的窄栏）：宽度立刻变好，工具栏和列表随后滑进来。
- **按钮**：播放栏、顶栏、筛选标签和登录页的按钮，鼠标移上去时稍微放大，按下时稍微缩小，幅度和 foobar2k 一样。切换随机、循环、歌词、队列、设备、静音和右侧面板时，按钮上的图标轻弹一下。
- **进场动画**：切换筛选标签后的内容、播放队列的前 8 首（依次错开出现）、换了出声设备后的设备卡片、「浏览全部」的流派瓷砖、登录卡片。
- **修正**：
  - 关掉「动画效果」时，全屏歌词页直接跳到正在唱的那句，不再滚过去。
  - 图标在还没排好位置时就弹一下，以前会绕着左上角放大，现在绕着中心。

## 界面

- **标出你在哪一页**：在首页时，顶栏的「首页」变亮；在设置页时，「设置」变成琥珀色。左侧音乐库里正在看的歌单、专辑或艺人加一层淡底色，和正在播放的那一项（琥珀色名字、跳动的电平条）区分开。
- **播放条**：
  - 进度条和音量条改成和设备面板一样的细滑块。
  - 进度条平时是白色，鼠标移上去或拖动时变成琥珀色。
  - 窗口窄的时候，进度条不再被挤得很短。
- **专辑页**：编码、采样率、位深改成一排小徽章，Hi-Res 用琥珀色底。
- **全屏歌词页**：顶部显示歌名和艺人，点歌名打开专辑，点艺人打开艺人页。关着右侧面板时，也知道是哪首歌的歌词。
- **左右留白**：关掉右侧面板后，中间页面左右都留 8 像素，以前右边多出 8 像素。
- **设置页**：「界面缩放」的五档排成一行，从小到大；「播放顺序」按行从左往右读。
- **对齐**：
  - 流派页没有封面时，标题不再往右偏。
  - 搜索页「最佳结果」的头像改为靠左，和下面的文字对齐；鼠标移上去整张卡片变亮。
  - 「浏览全部」的流派瓷砖按窗口宽度铺满一行，鼠标移上去时角落里的封面会转一下。
- **登录页**：
  - 卡片里的「Sonus」改用标题字体，卡片加了细边和阴影。
  - 在浏览器里登录时，等待框里的两个按钮看得出是按钮了，登录代码用琥珀色突出。
- **弹窗**（更新、重命名、删除确认、属性等）改成和面板一样的冷色深底，不再偏暖灰。
- **断网时**，右上角的「未连接到服务器」用淡红底、白字，更显眼。错误提示左边的红条加了圆角。
- **右侧面板**：
  - 没有在播放时，提示放在正中间。
  - 音频信息里的采样率、位深、码率等数字改用等宽的数字字体。
- 左侧音乐库的排序框收窄了，搜索框宽了一些。

## 测试情况

- 核心库测试 114 项全部通过。
- 静默端到端验收，十四轮：x64 和 ARM64 各一遍，每遍 108 / 108 通过（1 项跳过：第 1 版才有的「接着播放」提示），每轮的静默检查都确认测试窗口没有出现在屏幕上，每个测试实例都正常退出。
- 来回切换 60 次页面后，界面元素和内存不再增长（ARM64：2765 → 2765 个元素；x64：2763 → 2763 个）。
- 性能测试（ARM64，演示曲库放大 8 倍：2344 首、272 张专辑），改动前后各测两遍：
  - 界面线程最长卡顿：改动前 368 / 446 毫秒，改动后 314 / 364 毫秒。两边最长的一次都在登录时。
  - 内存最高：改动前 517 / 505 MB，改动后 484 / 499 MB。
- 看过的截图：设置页、窄窗口、专辑页的音质徽章、浏览器登录的等待框、更新弹窗、断网时的右上角和错误提示、「浏览全部」的流派瓷砖。
- 这台测试电脑是 ARM 电脑，x64 版是在上面模拟运行的。
- **还没有验证的**：
  - 测试实例不用真鼠标，鼠标移上去和按下时的缩放、悬停颜色都没有自动测过。悬停颜色另用不动鼠标的办法逐个检查过。
  - 截图只拍到动画结束后的样子，动画本身是在可见的测试版里用眼睛看的。
  - 没有在两台真实的电脑上试过。
