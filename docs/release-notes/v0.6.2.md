# Sonus 0.6.2

设备面板照 Spotify 重做了：点播放栏右边的设备按钮，设备列表出现在右侧面板里；别的设备在出声时，播放栏下面有一条琥珀色的横条写着在哪台上播放。另外，打开正在播放的歌单或专辑时，列表直接停在正在播的那首。

## 下载

| 文件 | 说明 |
|---|---|
| `Sonus-0.6.2-x64-setup.exe` | 安装程序，普通 Intel / AMD 电脑（推荐） |
| `Sonus-0.6.2-ARM64-setup.exe` | 安装程序，骁龙等 ARM 电脑（推荐） |
| `Sonus-0.6.2-x64.msi`、`Sonus-0.6.2-ARM64.msi` | 和安装程序里装的是同一个 MSI |
| `CreeperUX-Music-0.6.2-x64-setup.exe`、`CreeperUX-Music-0.6.2-ARM64-setup.exe` | 和上面的安装程序完全相同，只是用了旧名字：0.3.0 按这个名字找更新 |

只为当前用户安装，不需要管理员权限，装在 `%LOCALAPPDATA%\Programs\Sonus`。安装程序没有数字签名，第一次运行时 SmartScreen 可能会提示，选「更多信息 › 仍要运行」。

## 新的设备面板

- **设备按钮像「播放队列」按钮一样，点一下打开、再点一下收起。** 设备列表「连接到设备」出现在右侧面板里，不再是弹出的小窗。
- **最上面一张卡片是正在出声的设备**：名字用强调色，写着正在播放或已暂停，有跳动的电平条，下面是它的音量。没有设备在播放时，卡片显示这台电脑和「没有设备在播放」，按播放就在这台上放。
- **卡片下面是其他设备，每台一行。** 点一行就把播放转过去，面板留着不关（和 Spotify 一样）；行尾的喇叭按钮调那台的音量。
- **最下面是「没看到你的设备？」**，说明怎样让设备出现在这里。
- **别的设备在出声时，播放栏下面有一条琥珀色的横条**：「正在「…」上播放」，点它打开设备面板。歌名下面那一行现在只在没有设备播放时出现，写「上次在「…」播放」。
- 服务器只提供第 1 版多设备协议时，用的也是这个面板。

## 打开正在播放的列表，直接停在正在播的那首

- 打开正在播放的歌单、专辑、流派或搜索结果时，列表自动滚到正在播的那首，放在中间，不用再自己往下找。
- 只在打开时跳一次，之后自己滚动不会被拉回去。
- 同一首歌在歌单里出现两次时，停在正在放的那一处。
- 歌单的歌曲晚一点才从服务器读到时，读到后也会跳过去。

## 测试情况

- 核心库测试 114 项全部通过。
- 静默端到端验收，十四轮，对演示服务器，从源码构建的 ARM64 程序：94 / 94 通过（1 项跳过：第 1 版才有的「接着播放」提示）。演示服务器只提供第 1 版时，相关几轮 40 / 40 通过。
- 新增一项：在「媒体库 · 全部歌曲」里放第 201 首，回首页再打开这个列表，第 201 首就在视野里。用 0.6.1 跑这一项会失败。
- 同样的十四轮对真正的 Sonus 服务器（53 首、每首 70 到 130 秒的测试曲库，一次性用户）：94 / 94 通过，4 项跳过（曲库里没有 DSD 歌曲；大封面在前几轮已经取过；第 1 版的「接着播放」提示；「单独切断一台设备的网络」只有演示服务器做得到）。
- 看过的截图：别的电脑在播放时的设备面板和横条；把播放转到这台以后；没有设备播放时；第 1 版的设备面板；回到正在播放的列表时第 201 首在中间、标着正在播放。
- **还没有验证的**：测试实例不用真鼠标，所以鼠标移上去整行变亮、喇叭按钮弹出的音量条、面板滑入的动画都没测过；也没有在两台真实的电脑上试过。
