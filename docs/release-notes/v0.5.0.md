# Sonus 0.5.0

可以在浏览器中登录了，Sonus 不再经手账号密码。检查更新不再需要 GitHub 令牌。窗口最大化时右上角按钮点不动的问题也修好了。

## 下载

| 文件 | 说明 |
|---|---|
| `Sonus-0.5.0-x64-setup.exe` | 安装程序，普通 Intel / AMD 电脑（推荐） |
| `Sonus-0.5.0-ARM64-setup.exe` | 安装程序，骁龙等 ARM 电脑（推荐） |
| `Sonus-0.5.0-x64.msi`、`Sonus-0.5.0-ARM64.msi` | 和安装程序里装的是同一个 MSI |
| `CreeperUX-Music-0.5.0-x64-setup.exe`、`CreeperUX-Music-0.5.0-ARM64-setup.exe` | 和上面的安装程序完全相同，只是用了旧名字：0.3.0 按这个名字找更新 |

只为当前用户安装，不需要管理员权限，装在 `%LOCALAPPDATA%\Programs\Sonus`。安装程序没有数字签名，第一次运行时 SmartScreen 可能会提示，选「更多信息 › 仍要运行」。

## 新功能：在浏览器中登录

- 登录页填好服务器地址后，点「在浏览器中登录」：
  1. Sonus 显示一个登录代码（如 `BCDF-GHJK`），并在浏览器里打开服务器的允许页。
  2. 在网页上登录。服务器开了二步验证时，在这里输入验证码。
  3. 确认网页上的代码和 Sonus 里的一样，点「允许」，Sonus 就自动登录了。
- Sonus 拿到的是服务器专门发给这台电脑的应用密钥，自始至终不经手账号密码。
  - 密钥列在服务器网页个人设置的「应用专用密码」里，名字是「Sonus · 电脑名」，随时可以撤销。
  - 在 Sonus 里退出登录时，会把密钥还给服务器，密钥随即失效。
- 设置页「账号」一节会写明用的是哪种登录方式。
- 用户名加密码登录照常可用。密码不对时，提示里会建议改用浏览器登录或应用专用密码：服务器开了二步验证后，账号密码在这里就用不了了。
- 需要 CreeperUX 改版的 Navidrome（`ghcr.io/creeperux/navidrome:latest`，2026-11-24 及以后的镜像）。服务器不支持时，点这个按钮会提示改用用户名和密码。

## 更新不再需要 GitHub 令牌

- Sonus 的仓库（CreeperUX/CreeperUX-Music）已经公开，检查和下载更新都直接访问 GitHub，不用登录。安装程序下载后照样按 GitHub 记录的 SHA-256 校验。
- 「设置 › 更新」里不再有填令牌的地方，改成一句说明，并附上「在 GitHub 上查看所有版本」的链接。
- 旧版本保存的 GitHub 令牌（凭据管理器里的 `Sonus:github`，以及更早的 `CreeperUXMusic:github`）在 0.5.0 第一次启动时删掉。
- 从 0.4.0 升级：在程序里点「新版本」即可，旧令牌对公开仓库照样有效。如果令牌已经过期，就到 GitHub 的 Releases 页面下载安装程序直接运行。

## 修复

- 窗口最大化时，右上角的最小化、最大化和关闭按钮点了没反应：顶栏给自己的按钮留出的点击区域没跟上布局变化，盖住了窗口按钮。现在每次布局后都重新测量，而且不会再盖住窗口按钮。
- 退出登录后，「接着上次听」的提示还留在登录页上，点里面的「接着播放」会调用已经关掉的会话。现在退出时一并清掉。

## 测试情况

- 核心库测试 105 项全部通过。新增的测试覆盖用 API 密钥登录、浏览器登录的发起、轮询和交还密钥，以及检查更新的请求不带凭据。
- 静默端到端验收，十四轮，用 MSI 解出的程序跑：
  - ARM64：85 / 85 通过。
  - x64（在 ARM 电脑上模拟运行）：85 / 85 通过。
  - 新增「在浏览器中登录」一轮：允许、拒绝、取消，重启后用保存的密钥直接登录，退出时交还密钥。
  - 「检查更新」一轮改为确认请求里不带任何凭据；「从 CreeperUX Music 升级」一轮确认旧令牌被删掉。
- 服务器一侧（改版 Navidrome）：
  - Go 测试和网页的单元测试全部通过。
  - 在本地编译的改版服务器上，按「必须二步验证」配置，用无头浏览器走完整个允许流程，8 项全过：登录、绑定验证器、允许、拒绝、手动输入代码、交还后密钥失效。
  - 正式服务器已经换上这一版，确认新接口可用。
- 不带凭据访问真实的 GitHub：版本列表和安装程序下载都正常。
- 安装包：
  - 两个 MSI 都只解包、不安装，再用解出的程序跑验收。
  - 安装程序内嵌的 MSI 和单独的 MSI 一致，旧名字的安装程序和新名字的逐字节相同。
- 在正式服务器上用浏览器登录（包括第一次绑定验证器）还没有人从头到尾走过一遍。

## 已知限制

- 安装程序没有数字签名。
- 界面只有中文。
- 服务器的网页登录页在登录前是英文的：Navidrome 登录之后才加载界面语言。
