# Sonus 0.7.0

全面打磨了 Windows 版的界面细节与动效手感：右侧面板与「连接到设备」补上了清晰的滑入滑出和抽屉升起下沉动效（PR #49），同时打磨了切歌、换页、音乐库展开收起、播放栏滑块、顶栏与音乐库当前页高亮、专辑音质徽章、全屏歌词标题栏，以及十余处对齐和配色一致性问题。

## 下载

| 文件 | 说明 |
|---|---|
| `Sonus-0.7.0-x64-setup.exe` | 安装程序，普通 Intel / AMD 电脑（推荐） |
| `Sonus-0.7.0-ARM64-setup.exe` | 安装程序，骁龙等 ARM 电脑（推荐） |
| `Sonus-0.7.0-x64.msi`、`Sonus-0.7.0-ARM64.msi` | 和安装程序里装的是同一个 MSI |
| `CreeperUX-Music-0.7.0-x64-setup.exe`、`CreeperUX-Music-0.7.0-ARM64-setup.exe` | 和上面的安装程序完全相同，只是用了旧名字：0.3.0 按这个名字找更新 |

只为当前用户安装，不需要管理员权限，装在 `%LOCALAPPDATA%\Programs\Sonus`。安装程序没有数字签名，第一次运行时 SmartScreen 可能会提示，选「更多信息 › 仍要运行」。

## 动效打磨

全部动效都在 Windows 合成器上运行，不给界面线程增加负担，也不做逐帧改宽度的布局动画；关闭 Windows「动画效果」时直接显示结果。

- **右侧面板与设备抽屉（PR #49）**：打开和关闭右侧面板时从右侧平滑滑入滑出；打开「连接到设备」时设备列表作为抽屉从面板底边升起并盖住原内容，关闭时向下沉回，中途反向操作能从当前位置无缝接续。
- **播放条换歌与跨设备提示条**：切歌时底部封面轻微放大入场，歌名和艺人轻柔横向滑入淡入；别的设备开始出声时，底部的琥珀色「正在「…」上播放」横条从下方轻升出现，设备按钮同步轻弹提示，停止时顺滑沉回（可打断）。
- **换页与搜索**：普通切换页面平滑上浮淡入，搜索框边输入边刷新结果时改为轻柔纯淡入，不再每打一个字整页上下跳动。
- **音乐库展开与收起**：在 300 px 列表与 80 px 封面栏间切换时布局立刻到位，工具栏与列表内容在合成器上做顺滑的滑入与过渡。
- **按钮与视图交互反馈**：播放栏、顶栏、筛选芯片和登录页按钮统一采用 foobar2k 的 1.04 / 0.97 悬停与按下缩放反馈；切换随机、循环、歌词、队列、设备、静音和右侧面板开关时图标克制轻弹；筛选芯片切内容、切入播放队列（前 8 行错峰上浮）、切换出声设备、打开流派浏览和登录页均有清晰自然的入场动效。
- **修正**：全屏歌词页滚动补上尊重 Windows 动画开关（`disableAnimation: !Motion.Enabled`）；修正图标初次布局前缩放中心点偏移的问题。

## 界面与排版细节

- **当前所在位置一目了然**：在首页时顶栏「首页」图标变亮，在设置页时「设置」图标变为琥珀色；左侧音乐库正在浏览的那一项加上柔和底色，和「正在播放」的琥珀字与跳动电平条区分开。
- **播放条滑块与窄窗口适配**：播放进度条和音量条统一到与设备面板一致的 3 px 纤细轨道与 12 px 圆形滑块；进度条平时呈素白色，悬停或拖动时变为琥珀色；窄窗口下放宽中栏空间，进度条不再被挤得过短。
- **专辑音质徽章与全屏歌词标题**：专辑页的编码与采样率/位深改为紧凑等宽胶囊徽章（`Hi-Res` 使用琥珀底色）；全屏歌词页顶部显示可点击的歌名与艺人，收起右侧面板时也能知道正在看哪首歌的歌词。
- **三栏对称留白**：关闭右侧面板后，中间主面板左右外边距保持对称的 8 px，不再在右侧多出 8 px 空隙。
- **设置页与各页对齐**：设置页「界面缩放」（80%–125%）一行按顺序排齐，「播放顺序」按行从左到右阅读；流派页无封面时标题与下方播放键齐平；搜索页「最佳结果」圆形头像改为左对齐并补悬停反馈；「浏览全部」流派瓷砖自适应填满整行宽度，悬停时右下角封面轻转放大。
- **登录页、弹窗与状态提示**：登录卡片里的「Sonus」统一使用 Chakra Petch 标题字体并补细边与阴影，浏览器登录等待框内的按钮与底色清晰区分、登录代码以琥珀色突出；弹窗（更新、重命名、删除确认、属性）统一采用 Sonus 的冷深色调，不再偏暖灰；断网时右上角「未连接到服务器」改为柔红底亮字更醒目，错误提示左侧红条补圆角；右侧面板未播放时改为居中柔和空状态，音频信息里的采样率、位深、码率、回放增益和文件大小统一使用等宽数字字体；左侧音乐库排序框收窄以留出更多搜索空间。

## 测试情况

- 核心库单元测试：**114 / 114 通过**。
- 在隔离桌面环境下运行 ARM64 完整十四轮验收：全部功能检查与日志检查通过（93 项功能/日志通过，1 项跳过：Connect 第 2 版不适用的第 1 版「接着播放」提示；所有测试实例退出码均为 `0x00000000`，日志零异常）。其中 12 轮静默检查报 `LOUD visible`、第 9 轮系统媒体控制（SMTC）未在主桌面媒体会话中出现，系运行环境的隔离桌面限制，需在正常桌面上由 ARM64 与 x64 复测确认。
- 界面线程性能对比（`perf.mjs`，ARM64，8 倍演示曲库 2344 首 / 272 张专辑，同一环境）：最长卡顿 **597 ms → 528 ms**，最高内存 **543 MB → 518 MB**；连续切换 60 次页面后界面元素与托管内存无增长（`2763 → 2763`，`7.1 MB → 4.7 MB`）。
- x64 编译通过（0 警告，0 错误）。
- 视觉与动效手感待在真机可见测试版（`node tools/e2e/preview.mjs`）中核验，并由审查会话在正常桌面补跑 ARM64 与 x64 完整验收。
