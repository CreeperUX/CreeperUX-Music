# Sonus 安卓版 0.5.0（测试版）

播放器支持左右滑动切歌，修复设置页按钮描边、手机状态栏遮挡与登录过渡期双主界面问题。

## 下载

装着 0.4.x 的话，在 设置 › 更新 里就能更新到这一版。也可以下载附件里的 APK 直接覆盖安装：装上后叫「Sonus 测试版」（包名 `com.creeperux.sonus.debug`，版本 0.5.0），需要 Android 13 及以上，登录不丢。

## 新功能

- **左右滑动切歌（参考 Spotify 手感）。**
  - **手机全屏播放器（封面视图）**：手指左右拖动封面，封面跟手滑出屏幕边缘，旁边露出下一首或上一首的真实封面；拖动超过一定距离或快速甩动即切歌，否则平滑弹回。仅在封面视图生效，不影响歌词和队列的滚动。
  - **手机迷你播放条**：左右拖动歌曲区域跟手切歌，卡片底色、喜欢和播放/暂停按钮保持不动。
  - **平板右侧「正在播放」面板**：大封面同样支持左右滑动切歌，上下拖动仍交给面板滚动。
  - **方向锁定不打架**：同一套手势检测在越过 touch slop 后锁定水平或竖直方向——水平切歌，竖直继续用于上拖打开／下拖收起播放器，不抢系统的预测性返回手势。
  - **向右滑永远切上一首**：按钮和媒体键仍保持「播放超过 3 秒回到本曲开头」，但向右滑看到的是上一首封面，因此滑动永远直接切上一首；Sonus Connect v2 协议、演示服务器与 Rust 服务器已同步为 `previous` 增加可选的 `force: true` 支持，本机与远程遥控模式行为一致。
  - **边界、动效与无障碍**：列表到头且未开启循环时轻柔阻尼回弹；完全随机模式下仍可滑动切歌；切歌伴随轻微振动；系统开启「移除动画」时直接切换不播动画；原有上一首／下一首按钮与读屏体验不受影响。

## 修正

- **设置页普通按钮与选项可见边界。** 在设置分组卡片（`raised` 背景）内的非主按钮（检查更新、退出登录、打开系统的媒体输出）与未选中选项改为更高一级底色并加细描边，深色和浅色模式下都清晰可辨。
- **手机滚动页面不再与状态栏文字重叠。** 设置、音乐库、全部列表页将状态栏内边距移到滚动区域外；首页、搜索、专辑、艺人、歌单、流派页在顶部保留彩色渐变延伸到状态栏，向下滚动时平滑升起不透明的状态栏衬底；并同步修正切换浅色／深色外观及打开全屏播放器时的状态栏图标对比度。
- **登录后不再短暂出现两个主界面。** `SonusRoot` 的 `AnimatedContent` 改为按各槽位自己的目标状态渲染，从「正在载入媒体库…」淡入主界面时不再同时组合两个 `Main`。

## 测试情况

- **服务器与协议**：
  - 演示服务器 Connect v2 单元测试 25 项全部通过（含 `previous` 的 `force: true` 用例）；`connect-vectors.json` 校验通过（15 组 172 步）。
  - Rust 服务器 `connect_vectors` 集成测试 3 项全部通过（含 `previous_with_force_skips_past_the_three_second_restart`）。
- **电脑上的 JVM 测试**：核心库 78 项通过（另 1 项手动读真实 GitHub 默认跳过，新增 `peekNext` / `peekPrevious` / `hasNext` / `hasPrevious` 覆盖全部播放顺序与边界，及 Connect 演示服务器 `force: true` 测试）；App 单元测试 19 项通过（新增方向锁定、滑动切歌与边界回弹、无动画模式、以及 `SonusRootTransition` 防双主界面测试）。
- **构建**：`:app:assembleDebug` 和 `:app:assemblePreview`（R8 压缩 + 基线配置）均通过。
- **设备测试**（两台模拟器同时对着演示服务器跑）：
  - 手机（`sonus-phone`）：10 项通过、跳过 1 项（二步验证，演示服务器没有），含新增的迷你播放条与全屏封面左右滑动切歌、播放超过 3 秒右滑直切上一首、第一首右滑回弹、封面下滑收起以及 Connect v2 远程滑动测试。
  - 平板（`sonus-tablet`）：10 项通过、跳过 1 项（二步验证），含新增的右侧面板封面左右滑动切歌、播放超过 3 秒右滑直切上一首、边界回弹以及 Connect v2 远程滑动测试。
- **手感与画面检查**：在手机与平板模拟器上安装 Preview 包实测并截取了静止、拖动途中、松手后、设置页深浅色及滚动状态栏截图。
- **未验证项**：真机尚未实测；未对着 Rust 服务器跑完整 `server-library.mjs` 设备测试（Rust 协议逻辑已由 `connect_vectors` 测试覆盖）。

## 已知限制

- 同 0.4.x：安装需经过系统确认；发新测试版需升版本号；正式版签名密钥尚未建立。
- 若连接的旧版服务器尚未更新支持 `previous` 的 `force: true` 字段，远程模式下播放超过 3 秒向右滑会退回为回到本曲开头。
