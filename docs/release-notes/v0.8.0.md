# Sonus 0.8.0

这一版换上了纯 C# 自带解码 + WASAPI 的新播放核心，彻底摆脱 Windows Media Foundation 在 FLAC 跳转、从中间接手和坏帧上的限制；同时接上服务器的播放库（`sonusRenditions`），新增音质设置、基于 EBU R128 响度的音量均衡、播放栏当前音质徽标和「始终用原文件」高级开关。

## 下载

| 文件 | 说明 |
|---|---|
| `Sonus-0.8.0-x64-setup.exe` | 安装程序，普通 Intel / AMD 电脑（推荐） |
| `Sonus-0.8.0-ARM64-setup.exe` | 安装程序，骁龙等 ARM 电脑（推荐） |
| `Sonus-0.8.0-x64.msi`、`Sonus-0.8.0-ARM64.msi` | 和安装程序里装的是同一个 MSI |
| `CreeperUX-Music-0.8.0-x64-setup.exe`、`CreeperUX-Music-0.8.0-ARM64-setup.exe` | 和上面的安装程序完全相同，只是用了旧名字：0.3.0 按这个名字找更新 |

只为当前用户安装，不需要管理员权限，装在 `%LOCALAPPDATA%\Programs\Sonus`。安装程序没有数字签名，第一次运行时 SmartScreen 可能会提示，选「更多信息 › 仍要运行」。

## 播放核心

- **纯 C# 自带解码 + WASAPI 输出（默认）**：内置 FLAC、Ogg/Opus（`Concentus`）、WAV 与 MP3（`NLayer`）解码器，零原生 DLL 依赖，ARM64 与 x64 行为一致；M4A/AAC/ALAC 等小众容器自动无缝回退到旧核心处理。
- **按字节范围即时跳转与接手**：按 FLAC `SEEKTABLE` 与 Ogg 二分寻址直接请求目标位置附近字节，不再从头下载整首 FLAC。实测真实 Rust 服务器上 44.1 kHz FLAC 跳进度约 184 ms、开播即跳约 372 ms、双端中间接手约 185–200 ms（旧核心为 2.4–2.6 秒）。
- **精确无缝衔接**：按采样边界无缝拼接下一首（含 Opus `pre_skip` 精确裁切），预加载仅拉取 64 KB 文件头，不占用额外流连接。
- **坏帧容错**：曲中遇到个别损坏帧时跳过坏帧继续播放，不再整首 `DecodeError` 放弃。
- **新旧核心并存可切换**（设置 › 高级 › 播放核心）：默认使用「新（自带解码）」，如遇问题可随时一键切回「旧（Windows Media Foundation）」。
- **系统媒体控制（SMTC）**：通过 `ISystemMediaTransportControlsInterop` 直接接入当前窗口，支持键盘媒体键、音量浮层封面与进度显示。

## 音质与音量

- **Wi-Fi 下的音质**（设置 › 音质与音量）：自动 / 普通 / 高 / 极高 / 无损，默认「自动」（= 无损，保留原采样率与位深）。
- **移动网络下的音质**（设置 › 音质与音量）：自动 / 普通 / 高 / 极高 / 无损，默认「自动」（= 高，Opus 160）；电脑默认按 Wi-Fi 处理，连接计费网络（如手机热点）时按移动网络处理，切换网络后下一首生效。两项均选「无损」即为强制无损。
  - 网速跟不上导致持续缓冲时，仅在选了「自动」时临时降一档，手动选定的档位不会自动降档。
  - 在开启播放库的服务器上，DSF、APE 等格式也能以无损 FLAC（DSD 经线性相位 FIR 低通滤波转 88.2 kHz/24 位）播放。
- **音量均衡**（设置 › 音质与音量）：默认「关」，可选安静（−18 LUFS）/ 正常（−14 LUFS）/ 大声（−11 LUFS），开启时默认「按专辑」（可切「按歌曲」）。
  - 新播放核心支持在浮点混音阶段正向提升响度并附带真峰值防削波保护与软限幅器，不再受 MediaPlayer 100% 音量上限限制；未开启播放库的服务器自动回退到曲目回放增益标签。
- **始终用原文件**（设置 › 高级）：默认关闭；开启后始终直接请求服务器原始文件，音质设置不生效，便于排查或对比。
- **播放栏当前音质徽标**：在歌名与艺人下方显示当前实际播放的格式与规格（例如 `无损 · 96 kHz/24 位`、`无损 · 44.1 kHz/16 位`、`Opus 160`），优先取服务器返回的 `X-Sonus-*` 响应头。

## 修正

- **修正 0.7.0 从中间接手 FLAC 跳到下一首的问题**：旧播放核心改为先打开、跳到目标位置再播放；新核心按寻址表直接从目标字节起播，同时彻底解决开播瞬间立刻跳进度失败的问题。

## 测试情况

- 核心库测试（`dotnet test tests/Sonus.Core.Tests`）：**134 / 134 全部通过**（较 0.7.0 的 114 项新增 20 项，覆盖 FLAC/Opus/WAV/MP3 解码与寻址、坏帧容错、零采样无缝衔接、档位与自动降档策略、EBU R128 响度与峰值保护、`getSonusRenditions` 解析）。
- 端到端验收（演示服务器，全套十四轮）：
  - **x64（Native 核心）**：**98 / 98 功能检查全部通过**（1 项跳过：Connect v1 专属「接着播放」提示），0 条日志异常；跳进度 245 ms、FLAC 开播即跳 384 ms、双端中间接手 FLAC 199 ms；来回切换 60 次页面后界面元素 `2765 → 2765`、内存 `7.3 → 7.7 MB`。
  - **ARM64（Native 核心）**：完整验收与新增第 3 步音质/响度/徽标/持久化检查全部通过（0 条日志异常）；跳进度 195–201 ms、FLAC 开播即跳 360–374 ms、双端中间接手 200 ms。
  - **ARM64（Legacy 核心）**：`signin,playback,connect,restart` 46/46 功能检查通过（0 条日志异常）。
- **开启播放库的真实 Rust 服务器端到端联调**（`SONUS_RENDITIONS_ENABLED=true` + 真实 ffmpeg，55 首含真实 FLAC）：
  - `getOpenSubsonicExtensions` 协商 `sonusRenditions v1`，`getSonusRenditions` 返回四档播放版与 EBU R128 响度（−17.7 LUFS）。
  - Wi-Fi 自动 → `X-Sonus-Quality: lossless` / `flac`，徽标 `无损 · 44.1 kHz/16 位`。
  - 音量均衡（正常 −14 LUFS）→ 增益精确提升至 `1.5311×`。
  - Wi-Fi 切换高 / 普通 → `X-Sonus-Quality: high` (`Opus 160`) / `normal` (`Opus 96`)。
  - 开启「始终用原文件」→ 忽略普通档设置，`X-Sonus-Quality: original` (`无损 · 44.1 kHz/16 位`)。
- MSI 打包验证（`tools/package.ps1 -Extract`）：ARM64（69 MB）与 x64（72 MB）均打入全部 4 个纯托管解码/WASAPI 程序集，解出运行通过 `signin,playback` 全部功能检查。
- **环境说明（诚实记录）**：本机代理测试运行在隔离的无 Explorer 桌面（`exebox`），因此 `shot.ps1 -Quiet`（DWM cloak 检测）与第 9 轮 `smtc` 跨会话枚举在新旧核心上均表现为相同的环境限制；发布前建议在普通交互式桌面复验一次静默检查与 SMTC 系统浮层。
