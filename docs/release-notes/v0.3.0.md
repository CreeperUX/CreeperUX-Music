# CreeperUX Music 0.3.0

第一个发布版：有了安装程序和更新通道（和 Lumen 同样的做法），界面、封面和速度也都重新打磨了一遍。

## 下载

| 文件 | 说明 |
|---|---|
| `CreeperUX-Music-0.3.0-x64-setup.exe` | 安装程序，普通 Intel / AMD 电脑（推荐） |
| `CreeperUX-Music-0.3.0-ARM64-setup.exe` | 安装程序，骁龙等 ARM 电脑（推荐） |
| `CreeperUX-Music-0.3.0-x64.msi`、`CreeperUX-Music-0.3.0-ARM64.msi` | 和安装程序里装的是同一个 MSI |

只为当前用户安装，不需要管理员权限，装在 `%LOCALAPPDATA%\Programs\CreeperUX Music`，开始菜单里有快捷方式。登录信息（Windows 凭据管理器）和设置（`%LOCALAPPDATA%\CreeperUX Music`）在升级和卸载时都会保留。安装程序没有数字签名，第一次运行时 SmartScreen 可能会提示，选「更多信息 › 仍要运行」。

## 新功能：检查更新

- 程序会从 GitHub 的 Release 检查新版本：启动后每天自动查一次，也可以在「设置 › 更新」手动查。
- 有新版本时右上角出现「新版本」提示。点它会显示版本说明，下载这台电脑架构的安装程序（按 GitHub 记录的 SHA-256 校验），然后关闭程序并打开安装程序。
- 默认只提示正式版，可以打开「接收测试版」。
- 仓库是私有的，需要在「设置 › 更新」里填一个只读的 GitHub 令牌：在 GitHub 新建 fine-grained token，Repository access 只选 CreeperUX/CreeperUX-Music，权限只给 Contents: Read-only。令牌保存在 Windows 凭据管理器中。

## 这一版的其他改动

**界面**
- 配色、字体和动效时长改用 foobar2k 的 CreeperUX 设计令牌，琥珀色和 foobar2k 一致；标题用 Chakra Petch 字体。
- 图标换成 CreeperUX 套件的图标，由 WinUI 自带的 PathIcon 绘制，刚启动时颜色就正确；右键菜单也用同一套图标。
- 顶栏重新排版：首页和搜索框在窗口正中，两侧对称。
- 新的应用图标（琥珀色圆环）。
- 界面缩放 80%–125%：「设置 › 显示」，或 Ctrl + = / Ctrl + - / Ctrl + 0。
- 动效改在合成器上运行，并和画面刷新对齐，不再一顿一顿。

**封面**
- 封面由程序自己下载和缓存，按屏幕缩放和界面缩放取合适的尺寸，显示清晰。
- 播放歌曲时封面不再加载不出来（以前和播放共用 Windows 的两个连接）。

**速度**
- 长歌单和媒体库列表只创建看得见的行，切换页面不再卡住。
- 启动时曲库和歌单同时载入；分页按服务器的页大小，一次取三页。
- 点「喜欢」立刻显示，后台按顺序发送；失败时恢复原样。
- 日志（`%LOCALAPPDATA%\CreeperUX Music\app.log`）记录启动各阶段、慢请求、开始播放和界面卡顿的耗时，方便排查。

**连接**
- 地址不写 `http://` 或 `https://` 时：局域网和 Tailscale 的地址先试 HTTP，连不上再试 HTTPS；其他地址用 HTTPS。
- 填外网的明文 `http://` 地址时，登录页和设置页会提醒：登录令牌会随每个请求明文经过互联网。

## 测试情况

- 核心库测试 82 项全部通过（新增检查更新、服务器地址的测试）。
- 静默端到端验收 69 / 69（x64、ARM64 各跑一遍），其中检查更新用本地的假 GitHub：令牌错误、找到正式版和测试版、下载并校验安装程序。
- 安装包：两个 MSI 都用管理员安装方式（只解出文件，不注册、不安装）解包，再用解出的程序跑完整验收；安装程序的每一页都离屏画出来检查过，内嵌的 MSI 和单独的 MSI 逐字节一致。
- 没有在电脑上真正运行过安装：第一次安装、以后的升级和卸载请你自己试一次。

## 已知限制

- 安装程序没有数字签名。
- 界面只有中文。
- 仓库还没有 LICENSE 文件。
