# Sonus 安卓版 0.5.1（测试版）

修正手机播放时同步断线后再也连不回来的问题：锁屏时最常见，其他设备会看不到手机的进度，也控制不了它。

## 下载

装着 0.4.x 或 0.5.0 的话，在 设置 › 更新 里就能更新到这一版。也可以下载附件里的 APK 直接覆盖安装：装上后叫「Sonus 测试版」（包名 `com.creeperux.sonus.debug`，版本 0.5.1），需要 Android 13 及以上，登录不丢。

## 修正

- **手机正在播放时，同步连接断开后能自己连回来。** 手机是正在播放的设备时，和服务器的同步连接（Sonus Connect）一旦断开一次（锁屏后手机省电、Wi-Fi 休眠、换网络时都容易断），重连时 App 要先告诉服务器「我还在播、播到哪里」。以前它在网络线程里读播放器状态，而播放器只允许在主线程读，于是出错，连接还没打招呼就断了；只要手机还是播放设备，之后每次重连都这样。结果是手机照常放歌，服务器和其他设备却看不到它的进度、也控制不了它。现在播放器状态改到主线程去读；就算读不到，招呼也照样发出，连接先连上。
- **连接出问题时记日志。** 同步连接失败的原因、招呼里哪一项没读到，都会写进系统日志（标签 `Sonus`），以后好查。

这个问题是从线上服务器的代理日志里查到的：11 月 28 日凌晨，手机的同步连接在几分钟里连了二十多次，每次刚连上就断，服务器一个字节都没发出去，同时手机还在正常拉歌、上报播放记录。

## 测试情况

- 修正前在平板模拟器上复现：先在平板上播放，锁屏，再断一次同步连接，之后一分半钟都没连回来（解锁、切到前台也一样），服务器上看不到这台设备，歌照常在放；重新启动 App（这时它还不是播放设备）半秒就连上。
- 电脑上的测试：核心库新增 2 项（招呼里要读的东西出错时招呼照样发出；断线后自己连回来，并且重新询问续播状态），对演示服务器通过。
- 设备测试新增 1 项：这台设备在播放时断线，能自己连回来，并且仍然是播放设备、仍在播放。
